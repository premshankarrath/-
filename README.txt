PREM SANKAR RATH — GITHUB WEBSITE

1. Upload index.html and the images folder to your new GitHub repository.
2. Replace images/photo1.jpg ... images/photo5.jpg with your five real photos.
3. The HTML is already configured for those exact filenames.
4. In GitHub: Settings → Pages → Deploy from branch → main → / (root).

IMPORTANT:
The five photos visible in the chat were not exposed to the file workspace as downloadable
image files, so this package contains local placeholder SVGs rather than pretending they are
your original photos. If you upload the five photos as actual attachments/files, they can be
placed into this package with the exact names photo1.jpg ... photo5.jpg.
